\chapter{Результаты эксперимента} \label{ch3}

\section{Условия проведения} \label{ch3:conditions}

Эксперимент выполнялся локально в каталоге \texttt{benchmark\_app}. Для каждого набора данных каждый фреймворк запускался пять раз. Метрики собирались для процесса тестового раннера по PID с помощью библиотеки \texttt{pidusage}~\cite{pidusage}. Все запуски завершились с кодом \texttt{0}.

Для JSON-набора использовано 4 строки суммарной длиной 17017 символов. Для CSV-набора использовано 4 строки суммарной длиной 8507 символов. В таблицах приведены среднее значение, стандартное отклонение и медиана.
