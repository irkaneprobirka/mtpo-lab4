\section{Входные данные переменной величины} \label{ch2:input}

JSON-файл содержит массив объектов \texttt{cases}. Каждый объект может задавать либо готовую строку \texttt{input}, либо шаблон \texttt{pattern} и длину \texttt{length}. Это позволяет хранить компактный файл и генерировать строки длиной в тысячи символов.

\begin{lstlisting}[breaklines=true]
{
  "name": "author-palindromes-json",
  "cases": [
    { "name": "uniform-5000", "pattern": "a", "length": 5000 },
    { "name": "alternating-5000", "pattern": "ab", "length": 5000 }
  ]
}
\end{lstlisting}

CSV-файл содержит поля \texttt{name}, \texttt{pattern}, \texttt{length}, \texttt{expectedLongest}. Такой формат используется как альтернативный способ импорта данных.

\section{Эталонный и авторский примеры} \label{ch2:data}

Эталонный файл \texttt{reference-palindromes.json} содержит строку \texttt{abacaba}, используемую в описании алгоритма Манакера на сайте CP-Algorithms~\cite{cp-algorithms-manacher}. Для нее ожидается самый длинный палиндром \texttt{abacaba} и 12 палиндромных подстрок. Также добавлены строки \texttt{abba} и \texttt{abcdef}.

Авторский пример находится в \texttt{author-palindromes.json} и \texttt{author-palindromes.csv}. Он включает односимвольную строку длиной 5000, чередующуюся строку, зеркальную строку \texttt{levelracecarlevel} и повторение шаблона \texttt{abacaba}.

\section{Средства и подходы тестирования} \label{ch2:testing}

Все три фреймворка запускают один и тот же набор проверок. Отличается только синтаксис тестового раннера:
\begin{enumerate}
    \item Jest использует функцию \texttt{test} и утверждения \texttt{expect};
    \item Vitest использует совместимый стиль \texttt{test}/\texttt{expect};
    \item Mocha использует \texttt{describe}/\texttt{it} и стандартный модуль \texttt{node:assert/strict}.
\end{enumerate}

Путь к входному файлу передается через переменную окружения \texttt{TEST\_INPUT\_FILE}. Для увеличения нагрузки бенчмарк задает \texttt{TEST\_REPEAT\_COUNT=15}, то есть каждый фреймворк многократно прогоняет один и тот же набор строк.

\section{Инструкция по установке и запуску} \label{ch2:run}

Установка:
\begin{lstlisting}[breaklines=true]
cd benchmark_app
npm install
\end{lstlisting}

Проверка эталона:
\begin{lstlisting}[breaklines=true]
npm run verify
\end{lstlisting}

Демонстрационный запуск:
\begin{lstlisting}[breaklines=true]
npm run demo
\end{lstlisting}

Отдельный запуск тестов:
\begin{lstlisting}[breaklines=true]
npm run test:jest
npm run test:vitest
npm run test:mocha
\end{lstlisting}

Полное сравнение:
\begin{lstlisting}[breaklines=true]
npm run benchmark
npm run benchmark:csv
\end{lstlisting}
