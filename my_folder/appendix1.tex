\section*{Обычная проверка}
Этот пример показывает проверку одного входа. В файле алгоритма аналогичные примеры перечислены в таблице, а цикл создаёт отдельный тест для каждой строки таблицы.
\begin{Verbatim}[fontsize=\small,frame=single]
test('abba', () => {
  assert.deepEqual(manacher('abba'), {
    longest: 'abba', length: 4, count: 6,
  });
});
\end{Verbatim}
\section*{Различия запуска}
Jest предоставляет \code{describe} и \code{test}. Mocha импортирует \code{describe} и \code{it} под именем \code{test}. Vitest явно импортирует \code{describe} и \code{test} из своего пакета. Проверки используют одинаковый \code{node:assert/strict}. Тайм-ауты заданы в настройках фреймворков.
