\chapter{Регистрация тестов и пример проверки}\label{appendix-app-code}
Полный код находится в каталоге \code{benchmark_app}. Все три адаптера регистрируют общий каталог, сохраняя собственное исполнение каждого фреймворка.
\section*{Регистрация в Jest}
\begin{Verbatim}[fontsize=\footnotesize,frame=single]
const { registerTests } = require('../shared.cjs');
registerTests(describe,
  (name, check) => test(name, check, 30000));
\end{Verbatim}
\section*{Регистрация в Mocha}
\begin{Verbatim}[fontsize=\footnotesize,frame=single]
const { registerTests } = require('../shared.cjs');
registerTests(describe,
  (name, check) => it(name, function () {
    this.timeout(30000);
    return check();
  }));
\end{Verbatim}
\section*{Регистрация в Vitest}
\begin{Verbatim}[fontsize=\footnotesize,frame=single]
import { describe, test } from 'vitest';
import { createRequire } from 'node:module';
const { registerTests } =
  createRequire(import.meta.url)('../shared.cjs');
registerTests(describe,
  (name, check) => test(name, check, 30000));
\end{Verbatim}
\section*{Содержательная проверка}
Для \code{abba} используется явно заданный объект ожидания: \code{longest: 'abba'}, \code{length: 4}, \code{count: 6}. Сравнение выполняется через \code{assert.deepEqual} из строгого режима \code{node:assert/strict}. Логика сценария одна, поэтому изменения ожидания одновременно применяются ко всем трём раннерам.
